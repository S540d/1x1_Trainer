# 1x1 Trainer

Practice the multiplication tables (1×1 to 12×12) — a simple trainer for children, with four game modes and a journey through all tables.

## Open the app

- Web: [s540d.github.io/1x1_Trainer](https://s540d.github.io/1x1_Trainer/)
- Android: [<img src="https://play.google.com/intl/en_us/badges/static/images/badges/de_badge_web_generic.png" alt="Jetzt bei Google Play" height="60">](https://play.google.com/store/apps/details?id=com.sven4321.trainer1x1&referrer=utm_source%3Dgithub_readme%26utm_medium%3Dreferral%26utm_campaign%3Dweb_presence)

## What you can do

- **Four game modes:** result missing, first factor missing, second factor missing, or mixed.
- **Learning journey:** master one table after another and earn bronze, silver or gold.
- **Practice mode** that repeats the tasks you find hardest.
- **Child profiles:** several children, each with their own progress and badges.
- **Parent dashboard:** weekly review, accuracy per table and a practice tip.
- Instant right/wrong feedback, optional sounds, German and English, works offline.
